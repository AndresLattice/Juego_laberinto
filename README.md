# juego-backtracking

Laberinto donde se implementa el backtracking.

## Cómo jugar en Windows

Usar Python 3.12 o 3.13. Con 3.14 pygame todavía no se instala.

En la carpeta del juego, abrir una terminal y ejecutar:

```
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Teclas: ENTER empieza, ESPACIO tira el dado, las flechas mueven y ESC sale.
